# Commands to Push Your Project to GitHub

## STEP 1: Initialize Git and Add Files
cd F:\SummerProject
git init
git add .

## STEP 2: Check What Will Be Committed (Optional but Recommended)
git status

## STEP 3: Create First Commit
git commit -m "Initial commit: Full-stack e-commerce platform with Spring Boot and React

Features:
- Spring Boot 4.1 backend with PostgreSQL
- React 18 frontend with Vite
- Shopping cart and wishlist functionality
- Admin dashboard with analytics
- AI chatbot shopping assistant
- Order management and tracking
- Coupon system with 3 active coupons
- 35 unique products across 8 categories
- Secure authentication
- Responsive design with dark/light themes"

## STEP 4: Add Remote Repository
## Replace YOUR_USERNAME with your actual GitHub username
git remote add origin https://github.com/YOUR_USERNAME/E-Commerce.git

## STEP 5: Verify Remote
git remote -v

## STEP 6: Push to GitHub
git branch -M main
git push -u origin main

## Alternative: If your default branch is 'master'
# git push -u origin master

---

## If You Get Errors:

### Error: "remote origin already exists"
git remote remove origin
git remote add origin https://github.com/YOUR_USERNAME/E-Commerce.git

### Error: "refusing to merge unrelated histories"
git pull origin main --allow-unrelated-histories
git push -u origin main

### Error: Authentication failed
# Use GitHub Personal Access Token as password
# Generate at: https://github.com/settings/tokens

---

## After Successful Push:

Visit: https://github.com/YOUR_USERNAME/E-Commerce

You should see:
✅ All your files
✅ README.md displayed
✅ 35 products safe
✅ No passwords exposed
