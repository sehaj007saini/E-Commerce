## About Section (longer):
A comprehensive e-commerce web application developed during summer training (June-July 2024). Built with Spring Boot backend and React frontend, this project demonstrates modern full-stack development practices including RESTful APIs, secure authentication, database management, and responsive UI design. Features include product browsing with advanced filters, shopping cart, wishlist, order management, admin dashboard with analytics, coupon system, and an intelligent shopping assistant chatbot.
